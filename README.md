# Event-organizer
This project is in requirement of completion of PLP Software Engineering program.
I chose to create an event organization Databse management system as a real world use case.
This is meant to assist organizations manage and track all aspects of event organization using a centralized SQL database.
its features include but are not limited to:
  1. Event creation and management.
  2. Venue Allocation.
  3. Attendee registration and Ticketing.\
  4. Event scheduling
  5. Organizer role.
